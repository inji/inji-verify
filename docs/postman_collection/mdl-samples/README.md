# mDL (`mso_mdoc`) test samples

The fixed mDL samples, their `validUntil` dates and expected results are in [`verify-core/src/test/resources/mdl-samples`](../../../verify-core/src/test/resources/mdl-samples/README.md), where the verify-core unit tests load them from the classpath.

The Postman collection (`v2/vc-verification` > `mso_mdoc`) embeds the same base64url strings, so no sample file is needed to run it.
